# Relia plugins

Public plugins and integration files for [Relia](https://tryrelia.com), which watches your product in production and explains problems in plain words.

| Folder | What it is |
|---|---|
| [`plugins/relia`](plugins/relia) | Cursor plugin: the Relia MCP server plus skills to fix production issues and set Relia up in a repository |

Relia's MCP server: `https://devreliaapi.tryrelia.com/mcp` (sign in with your Relia account). Docs: [tryrelia.com/mcp](https://tryrelia.com/mcp). The PHP / Laravel package lives in [tryrelia/relia-php](https://github.com/tryrelia/relia-php).
