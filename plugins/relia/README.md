# Relia plugin for Cursor

[Relia](https://tryrelia.com) watches your product in production (users, APIs, database, servers, AI features) and explains problems in plain words. This plugin brings Relia into Cursor:

- **Relia MCP server** (`https://devreliaapi.tryrelia.com/mcp`): incidents, evidence (requests, logs, sessions, database queries, page speed, uptime, deploys), fix plans, and Ask Relia. You sign in with your Relia account the first time; nothing to paste.
- **Skills**: fix a production issue end to end, and set Relia up in a repository.

## Try

- "What needs my attention in Relia?"
- "Show me how to fix the top incident."
- "Did my last deploy break anything?"
- "Set up Relia in this repository."

Tools that change something (mark fixed, acknowledge, give feedback, report a change, create a project) never act without your confirmation.

## Requirements

A Relia account (free plan available) at [app.tryrelia.com](https://app.tryrelia.com). Docs: [tryrelia.com/mcp](https://tryrelia.com/mcp). Support: relia@alaknandainfoplus.com.
